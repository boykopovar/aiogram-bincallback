# Optional-поля

Любой поддерживаемый тип (`bool`, `int`, `Enum`, `List[Enum]`, вложенная модель) может быть обернут в `Optional[T]`.

```python
value: Optional[int] = bfield(bits=16, signed=False)
```

## Правила

- добавляет ровно 1 бит присутствия перед данными поля (`DEFAULT_BOOL_BITS`);
- при упаковке: если значение `None`, пишется `0` и данные поля пропускаются целиком; если не `None`, пишется `1` и следом данные поля в обычном формате;
- при распаковке: presence-бит читается первым, при `0` значение поля - `None`, дальнейшие биты этого поля не читаются;
- для вложенной модели presence-бит один на всю модель - при `None` весь битовый хвост вложенных полей не расходуется;
- вложенные `Optional`-поля внутри `Optional`-модели считаются независимо, каждое со своим presence-битом.

## Бюджет бит

Presence-бит учитывается в общем бюджете класса [(раздел 8)](08-size-limit.md) всегда (если `Optional`), независимо от того, будет ли конкретный экземпляр иметь значение `None`.

## Ограничение по типу

`Optional[Union[int, str]]` и любой `Union` более чем из одного не-`None` типа - `UnsupportedFieldTypeError`, даже если один из типов union поддерживаемый.

Далее: [Бюджет бит и лимит размера](08-size-limit.md).
