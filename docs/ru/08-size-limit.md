# Бюджет бит и лимит размера

## Константы

| Константа          | Значение | Смысл                                             |
|--------------------|---------:|---------------------------------------------------|
| `HEADER_BITS`      |       24 | размер заголовка (prefix + version)               |
| `PREFIX_BITS`      |       16 | ширина поля prefix в заголовке                    |
| `VERSION_BITS`     |        8 | ширина поля version в заголовке                   |
| `MAX_TOTAL_BITS`   |      440 | заголовок + payload, вычислено из лимита Telegram |
| `MAX_PAYLOAD_BITS` |      416 | `MAX_TOTAL_BITS - HEADER_BITS`, доступно под поля |

`MAX_TOTAL_BITS` получен из `MAX_CALLBACK_LENGTH = 64` символа base128-алфавита, округлено вниз до кратного 8 бит. Доступны как `BinaryCallbackData.max_total_bits()` / `.max_payload_bits()` - одинаковы для всех подклассов.

## Проверка при определении класса

Сумма бит всех полей плана (`plan_total_bits`, рекурсивно по вложенным моделям) сравнивается с `MAX_PAYLOAD_BITS` в момент определения класса (`__pydantic_init_subclass__`). Превышение - `SizeLimitExceededError` с фактическим и допустимым числом бит. Значение ровно на границе (`== MAX_PAYLOAD_BITS`) проходит без ошибки.

## Что входит в сумму

| Тип поля         | Вклад в бюджет                           |
|------------------|------------------------------------------|
| `bool`           | 1                                        |
| `int`            | `bits` (или 32 по умолчанию)             |
| `Enum`           | `bits`                                   |
| `List[Enum]`     | `len_bits + max_len * item_bits`         |
| вложенная модель | сумма бит всех ее полей, рекурсивно      |
| `Optional[...]`  | +1 к вкладу базового типа (presence-бит) |
