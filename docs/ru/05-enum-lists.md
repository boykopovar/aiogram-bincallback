# Списки enum

```python
class Direction(Enum):
    UP = "up"
    DOWN = "down"
    LEFT = "left"
    RIGHT = "right"


path: List[Direction] = bfield(max_len=4)
```

Единственный поддерживаемый тип списка - `List[SomeEnum]`, без `Optional` внутри списка. `List[int]`, `List[str]`, `List[Optional[Direction]]` - `UnsupportedFieldTypeError`.

## Параметры

| Параметр    | Обязателен | По умолчанию                                 |
|-------------|------------|----------------------------------------------|
| `max_len`   | да         | -, иначе `MissingMaxLenError`                |
| `bits`      | запрещен   | -, передача - `UnrecognizedBinFieldParamError` |
| `item_bits` | нет        | авто из `bin_order`                          |
| `bin_order` | нет        | `tuple(EnumCls)`                             |
| `signed`    | запрещен   | -, передача - `UnrecognizedBinFieldParamError` |

`max_len` - верхняя граница длины списка, закладывается в бюджет бит независимо от фактической длины конкретного экземпляра. Размер поля на проводе фиксирован и считается из `max_len`, не из текущего содержимого.

`bin_order` работает как для одиночного enum-поля (раздел 4): порядок членов и допустимое подмножество. Дубликаты - `DuplicateBinOrderError`.

## item_bits

Ширина одного элемента списка в битах. Если не передан - вычисляется автоматически как минимальное число бит для `len(bin_order)` значений.

Если передан явно - используется вместо автовычисления, но проходит ту же проверку, что и `bits` для одиночного enum: если `2 ** item_bits < len(bin_order)` - `InsufficientBitsError` с указанием реально требуемого числа бит. Передавать `item_bits` больше минимума допустимо (расширяет резерв на будущие значения enum без изменения формата уже упакованных данных).

## Формула размера

```
item_bits = item_bits явно, либо минимум бит для len(bin_order) значений
len_bits  = минимум бит для (max_len + 1) значений
total     = len_bits + max_len * item_bits
```

`len_bits` считается на `max_len + 1` вариантов длины (длина от `0` до `max_len` включительно). При `max_len=1` длина принимает 2 значения, значит `len_bits=1`. При `max_len=5` это 6 значений, значит `len_bits=3`.

`total` считается по `max_len`, не по фактической длине - пустой список и список максимальной длины в этом поле занимают одинаково места в бюджете класса (раздел 8). Большой `max_len` может сразу превысить бюджет, даже если реальный список короткий.

## Кодирование

Упаковка: длина списка в `len_bits`, затем индекс каждого элемента в `bin_order`, в `item_bits`. Порядок элементов сохраняется как есть, повторы допустимы.

Фактическая длина больше `max_len` - `ListLengthOverflowError` при `pack()` / `encode_fields`. Проверка только при кодировании: `Model.model_construct(path=[...])` с длиной больше `max_len` создается без ошибки, падает на `pack()`.

## describe

Список enum описывается как `[UP,DOWN]` - имена (или значения) членов через запятую в квадратных скобках. Настраивается через `EnumListDescribeOptions` (`as_name`, `separator`, `brackets`) - раздел 10.
